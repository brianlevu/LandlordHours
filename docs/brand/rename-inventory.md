# Dormer rename inventory

2026-10-27, branch `brand/dormer` (base `int/2.1-v2`). The app is renamed **Dormer** in 2.2.
This lane changed only the icon, the Home Screen name and the logo components. Everything below
still says "LandlordHours" or "Landlord Hours" and is for the later copy pass. Nothing here was edited.

**Counts:** 37 Swift strings + 4 catalog strings + 3 Info.plist strings + 1 StoreKit name
+ 4 assets/marks + 3 App Store Connect fields = **52 user-facing items**.
86 storage keys and identifiers are listed separately: **do not rename them.**

Rules for the pass: every new string goes through a String Catalog (CLAUDE.md "Voice"); use
`DormerBrand.name` (`Sources/Shared/DormerMark.swift`) where code needs the name; the Pro product
reads "Dormer Pro" only after the App Store Connect name changes (below), so the paywall never
disagrees with the purchase sheet.
