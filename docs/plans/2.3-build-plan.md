**Decisions this plan builds** (memory `next-update-backlog.md` items 6–8 and the "2.3 directions", "designs approved" and "small calls" blocks; `pricing-decision.md`):
- **Pricing.**
  - Everyone gets 1 rental free forever. The user picks it and can switch it once a calendar month in Settings. Other rentals are view-only, and their hours stay counted.
  - Pro is **$49.99/yr**, auto-renewing, with Apple's **14-day free trial**. Brian confirmed the price on 2026-10-31. The app never prints a price: copy shows StoreKit's `displayPrice`.
  - The trial starts from the paywall the first time a person taps a Pro feature.
  - Pro covers every rental, export, the care plan and learning.
  - Founding lifetime buyers (`com.openclaw.landlordhours.pro`) keep Pro forever. Family Sharing is off.
- **Day-12 reminder.** The sheet says "Keep Pro", with a "Cancel in Settings" link.
- **Care plan A.** Smart hour chips with one tap ("Last time 1h 20m", "Typical 1–2h", "30m"). The app never prefills a guessed number. A care prefill opens Log time with "How long" empty.
- **Rows and placement.** Care rows keep the chevron. The Learn card sits under To confirm. Swiping down the free-rental sheet keeps the most-used rental.
- **Lessons.** The critic's review is enough. Every lesson carries `learn.notAdvice`.
- **Nudges.** One option: opt-in settings with 4 kinds and quiet hours.
- **Toggle.** The stock iOS toggle is exempt from the contrast rule, in writing.

## 2. Gates per package

The validation tier is **shipping, user-visible**. Every package runs these in order:

1. **Builder self-check with the gate rubric** (`scripts/qa/gate_rubric.md` and DESIGN-STANDARD §5).
   - Run frame_check contrast on every text pair, density (`frame_check.py density`), XXL and AX3 clipping, and a token and retired-hue scan, in light and dark.
   - Hash-check that no two state frames are identical.
   - Run `standard_lint.py` (0 new) and `copy_gate.py` on the package's table.
   - Run the unit target. Known red: `CalibrationTests` until E lands.
   - Run the package's UI test classes and report the pass counts.
   - Every number comes from captured frames, with the raw file named in the hand-off.
   - Frames go to `~/AgentScratch/landlordhours/<date>/2.3-<pkg>/frames-rN/`, frozen. Name them with the approved frame ids (p1…, c1…).
2. **Fresh visual-gate** (`visual-gate` agent, Opus, never the author) per UI package (A, B, C, D, E's Today change).
   - It compares each frame to its approved frame side by side, pixel-measured.
   - These are new surfaces, so they get **two independent looks** on the first review and one look on fix rounds.
   - Note for the gates: the approved "xxl" frames were captured at xxLarge, not xxxLarge (measured by both foundation gates). Capture the package frames at the hi-fi's size (xxLarge) for like-for-like comparison. The DESIGN-STANDARD XXL rules still apply.
3. **Fresh verifier** (`verifier` agent, Opus). It reruns the unit and UI tests at the frozen SHA and checks the acceptance list. **Package A also gets an adversarial pass**, because it handles money and entitlements. A builder never closes its own gate.
4. **Merge.** The conductor merges `pkg/2.3-<name>` into `int/2.3` with `--no-ff`, then reruns the unit target and the touched UI classes on the merge commit before the next merge.

**Integration order.** E → A → C → B → D.
- **E first.** It turns the CalibrationTests red green and adds the navigation rule to the standard.
- **A next.** The other packages call its paywall entries `LockEntry.carePlan` and `LockEntry.learning`. Until A lands, they call `ProPaywallPresenter.present(entry: .settingsPro)` as a placeholder, which A replaces.
- **Then C, then B** (B's Today slot sits under C's).
- **D last.** It reads B's `CareDueSource`.

All five build in parallel from step 0. Only the merges are ordered.

**Jev steps** (the TypeSafe Jev approved judge, `typesafe-ai` skill, key `~/.config/typesafe/api_key`; cascade, not gate — a Jev-only pass never closes a gate):
