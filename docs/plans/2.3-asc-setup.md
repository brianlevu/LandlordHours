## Read-only checks (safe to run any time)

These take the machine-wide asc lock (ios-dev-harness §8) and pipe through `jq`.

```bash
asc subscriptions groups list --app "6759508794" | jq '.data[] | {id, name: .attributes.referenceName}'
asc subscriptions list --group-id "22533599" | jq '.data[] | {id, productId: .attributes.productId, state: .attributes.state, period: .attributes.subscriptionPeriod}'
asc subscriptions view --id "6829377043" | jq '.data.attributes'
asc subscriptions pricing summary --app "6759508794" | jq '.'
```

The flag names follow `asc subscriptions --help` (asc 5.4). If a subcommand's flags differ, check `asc subscriptions <sub> --help` before running.
