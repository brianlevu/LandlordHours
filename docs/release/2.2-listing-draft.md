### Facts behind the description (checked in the code, not in old copy)
- Pro terms: one non-consumable purchase, `com.openclaw.landlordhours.pro`, 29.99 USD in ASC (`asc iap pricing summary`), no subscription. Free covers one rental (`ProGate.freeRentals = 1`). Pro unlocks more rentals and export (`ProGate`: `isAtPropertyLimit`, `isExportLocked`). The `.storekit` file names it "Dormer Pro (Lifetime)". The description does not state the price.
- I did not list backup or "AI entry" as Pro features. ASC's IAP text and the `.storekit` text say they are, but `ProGate` locks only rentals and export.
- Voice: `VoiceEntryService` (Speech framework; mic and speech strings in Info.plist). Typed or spoken notes fill the entry (Log time note reading).
- Inbox finds rental work in the calendar and the user confirms (`Sources/Views/Inbox`, `NSCalendarsFullAccessUsageDescription`).
- iCloud: CloudKit private database, no sign-in (`docs/2.2-app-review-notes.md`).
- Export: PDF (`AuditReportPDFRenderer`) and a spreadsheet (`AuditReportCSV`). The copy says PDF only, to match the brief.
- Not claimed: the iPad / Duo layout and widgets (kept out to follow the brief; they could be added).
