## 2.2.1 sync

- **LOW: "Keep aside" for the held set pushes this phone's dirty settings under the household name.**
  When the household pair belongs to a set held as a question and the person answers "Not mine, keep
  them aside", the hold is released through the settings precedence (`releaseHousehold`). If this
  phone's settings are dirty (a real local edit), `.local` wins and the next push writes this phone's
  `GoalSettings-household` / `TaxProfile-household` over the other set's pair, under this phone's id.
  The other set's phones then ignore that pair (its owner is a held-apart set there), so nothing is
  lost, but the household pair name now carries this phone's values. Candidate fix: on "aside", mark
  the pair as another set's (`householdForeign`) instead of claiming it, and carry this phone's
  settings in its mirror pair only.
