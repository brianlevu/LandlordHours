## 4. Build packages (file-disjoint)

Each package owns its files; every file appears in exactly one package. Later packages **consume** package 0's and A's files and never edit them; a lane that needs a change there asks the 0/A owner. No two lanes edit one file at the same time. Two mechanical rules make this hold:
- **`project.pbxproj` is generated** from `project.yml` by `xcodegen`; lanes never hand-edit it. On merge, take either side and regenerate. `project.yml` is A's.
- **Strings go to per-package catalogs**: `Sources/Resources/Strings/<Package>.xcstrings` (for example `Today.xcstrings`), owned by that package, used with `String(localized:table:)`. Shared canonical keys (§C.5) live in `Localizable.xcstrings`, owned by A. `copy_gate.py` reads every `*.xcstrings` (Notes §9).
