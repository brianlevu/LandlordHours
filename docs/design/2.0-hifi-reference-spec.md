# LandlordHours 2.0 — hi-fi reference spec (Mobbin)

Date 2026-10-18. Research only, nothing in the repo changed. 80 PNGs at full res (1179×2676 = 3× of a 393pt-wide iPhone; divide px by 3 for pt). Every measurement below was read off those files; crops used for measuring are in `_measure-crops/`. No Mobbin result returned an `ai_usage_notice`.

This supersedes `design/direction.md` where they disagree. The references win.

## 0. Anchor apps (emulate their craft closely)

| Anchor | What we take | Why it fits LandlordHours |
|---|---|---|
| **Flighty** (primary) | Information hierarchy, type, status language, sheets, Live Activity, the "privacy footer", the paywall | The closest product analog: it auto-imports things from your calendar and email, then shows you live status. Data-forward, trustworthy, calm, and almost pure SF Pro + system materials. |
| **Bevel** | Home dashboard cards, metric cards (label → big number → status line), soft light surfaces, the "Automatic" checklist | Premium-but-calm health dashboard. One light grey canvas, white cards, color only on data and status. |
| **Mercury** | Restraint: flat hairline lists, money-grade number formatting, the "1 receipt needs attention" pill, zero-state honesty | The finance/trust register. Proves a screen can be 95% neutral and still feel expensive. |

Evaluated, not chosen as anchors: **Copilot** (great *To Review* pattern, but emoji-heavy, multi-hue tags, busy gradient header); **Gentler Streak** (lovely rounded type and floating tab bar, but mascot-led); **Oura** (editorial serif + photography, too moody for a tax tool); **Structured** (playful, saturated); **Things 3** (great list craft but 2017-era styling). Patterns from these are used per surface below.

### Craft specifics of the anchors (read off the images)
- **Type.** SF Pro throughout. Flighty: large title 34pt bold (`a-home/flighty-7`), sheet title 22pt semibold two lines, eyebrow 13–15pt semibold UPPERCASE secondary (`AA 6294 • FRI, 26 JUN`), hero time ~36pt semibold tinted by status (`c-detail/flighty-1`). Bevel: card label 15pt medium secondary with a 16pt glyph, value 32pt semibold + unit 22pt secondary, status 17pt medium tinted with a filled circle-arrow glyph (`a-home/bevel-2-trends`). Rich-text titles: Flighty bolds the nouns and leaves the joiner regular ("**San Francisco** to **Los Angeles**").
- **Spacing.** 16pt side margins on lists (Flighty, Mercury), 20pt on card canvases (Bevel). Card inner padding 16pt. Section gap 28–32pt. Row height 60–76pt for two-line rows.
- **Cards vs lists.** Flighty = sheets with plain hairline lists (inset 76pt so the hairline starts at text). Bevel = white cards radius 20pt on `#F2F3F7`, shadow barely visible (y 2, blur 12, black 4%). Mercury = no cards, full-width hairline sections.
- **Color restraint.** Neutral 90%+. Color is used for exactly three things: status (green on time / red late / amber attention), data (chart lines), and one action blue. Flighty's status words carry the color, not backgrounds.
- **Icons.** SF Symbols, mostly filled/circle variants at 15–17pt for status (`arrow.up.right.circle.fill`), regular weight line glyphs in lists; 44pt round glass/white buttons for close/share.
- **Motion** (not visible in stills; from the products): Flighty uses numeric content transitions on times and sheet detents; Bevel springs cards in place. Spec in §13.

## 13. Global visual language

### Font
- **SF Pro** (system default design) for everything: text, numbers, controls. This is what Flighty, Bevel, Mercury-iOS-feel and Apple Fitness read as. Numbers use `.monospacedDigit()`.
- **SF Pro Rounded**: no. None of the anchors use it; it reads "kids/fitness".
- **New York**: no in-app use. Previous direction proposed a serif hero numeral; none of the three anchors does it, and it was part of what read as "styled". (Option kept: New York only on the exported PDF title page, which is a document.)

### Type scale (Dynamic Type styles; pt at Large)
| Role | Style | Size/weight | Seen in |
|---|---|---|---|
| Hero number | custom, scales with `.largeTitle` | 48 semibold, tabular | Bevel value, Flighty times |
| Screen title | `.largeTitle` | 34 bold | Flighty "My Flights" |
| Onboarding title | `.title` | 28 bold | Flighty Calendar Sync |
| Sheet title / report section | `.title2` / `.title3` | 22 semibold / 20 semibold | Flighty detail, Bevel "Trends" |
| Row title / body | `.body` | 17 regular (semibold for emphasis nouns) | everywhere |
| Secondary / meta | `.subheadline` | 15 regular, `secondary` | Flighty eyebrow, Remote status |
| Eyebrow / section label | `.footnote` | 13 semibold UPPERCASE, tracking +0.3 | Copilot "TO REVIEW", Flighty |
| Unit label under number | `.caption2` | 11 semibold UPPERCASE | Flighty "HOURS" |
Never `lineLimit(1)` on titles; max two lines.

### 8pt grid
- Base 4pt, rhythm 8pt. Margins 16pt (lists) / 20pt (card canvas). Card padding 16–20pt. Gap between cards 12pt. Section gap 32pt. Row heights 44 (single), 52 (value row), 76 (two-line with tile). Tap targets ≥ 44pt.
- Radii: tile 10, chip/field 10, grouped list 16 (system), card 20, plan card 24, buttons = capsule. Concentric: inner radius = outer − padding.

### Materials and surfaces
- Light: canvas `systemGroupedBackground` (#F2F2F7), cards `secondarySystemGroupedBackground` (#FFFFFF), hairlines `separator`. Dark: system equivalents (#000 / #1C1C1E), not tinted copies.
- Liquid Glass (`.glassEffect`) only for floating chrome: tab bar, the separate `+` circle, 44pt close/share buttons, bottom action capsule in select mode. Never on content cards.
- Shadows: content cards none in dark, y2 blur12 4% in light. Floating buttons y4 blur16 10%.

### Accent and color use
- **One action color**: keep the brand violet but deepen for AA: light `#5B4CDB`, dark `#A99BFF` (replace `#7C6FF7`, which is too light for 17pt text on white). Used for primary capsules, links, selected states. That's it.
- **Status colors on words/glyphs, not fills**: positive `systemGreen` (#34C759 / dark #30D158) text weight semibold; caution `systemOrange`; destructive `systemRed`. Surfaces only for the status band and privacy footer at 6–10% wash.
- **Source hues** for record tiles only (blue calendar, green location, grey receipt, violet manual).
- Everything else neutral. No gradients except the paywall hero backdrop.

### Icon set
- **SF Symbols only** (in-app, widgets, Live Activities, notifications). Retire Lucide and LHIcon tab glyphs.
- Weights: `.regular` in lists and settings at 17–22pt; `.semibold` for status glyphs inline with semibold text; filled circle variants for status (`checkmark.circle.fill`, `exclamationmark.circle.fill`, `arrow.up.right.circle.fill`); `.hierarchical` rendering for source tiles; `.monochrome` in settings.
- Symbol effects: `.bounce` on confirm checkmark, `.contentTransition(.symbolEffect(.replace))` when a row flips Suggested → Logged.

### Motion
- Confirm: row checkmark bounce + `.sensoryFeedback(.success)`, row collapses with `.spring(response: 0.32, dampingFraction: 0.86)`, hero number counts up via `.numericText()`.
- Sheets: system detents. Press: scale 0.97, 120ms ease-out. Nothing animates on launch. Reduce Motion: crossfade 200ms.
