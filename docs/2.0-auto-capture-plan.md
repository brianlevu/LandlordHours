## Repo facts that shape the plan
- All records live in UserDefaults.standard (JSON under u.<id>.LandlordHours.*); extensions cannot read it → App Group drop box + index for extensions; no main-store migration.
- Background writers risk lost writes: AppDelegate.sharedViewModel is only set in onAppear (LandlordHoursApp.swift:732) → single AppModelHost owns the only AppViewModel.
- CloudKit additive fields are safe for 1.1 clients (.changedKeys), BUT the production schema must be deployed before the first TestFlight or batches fail.
- CalendarImportReviewView pre-selects all rows (bulk accept) → conflicts with confirm-first; retired.
- Widget code depends on EngagementDestination and hardcoded WidgetColor hexes (not action tokens).
- SDK (Xcode 27.1): PrivateCloudComputeLanguageModel iOS 27 (availability, isAvailable, quotaUsage, Error.quotaLimitReached), via LanguageModelSession.DynamicProfile.model(_:); images via Transcript.ImageAttachment; SystemLanguageModel iOS 26.

## Data model (additive only)
- TimeEntry: detectedAt?, confirmedAt?, sourceDetail? (decodeIfPresent).
- EntrySource: + calendarSuggested, receipt, location, shortcut, gmail, other (unknown future values → "Other", not "Manual").
- CloudKit: map new fields, never write nil.
- Suggestion (local only, never synced): Application Support/Capture/<userScope>/suggestions.json — id, sourceKey (dedupe), kind, detectedAt, start/end, proposedPropertyId/Category/Hours, hoursBasis (.scheduled/.dwellCap/.none), confidence, tier (rules/onDevice/pcc), state (pending/confirmed(entryId)/dismissed(reason)), evidence. Dedupe keys cal:<externalId>:<occurrenceISO>, rcpt:<sha256>, geo:<propertyId>:<arrivalISO>; dismissed keys kept; mute rules in same file; profile delete removes folder.
- Receipts: proposedHours always nil. Calendar detectedAt = max(firstSeen, eventEnd).
- Tests: frozen TimeEntryV11 decodes 2.0 JSON; 1.1 fixtures round-trip; unknown source renders "Other".

## Architecture
Detectors (calendar backfill 90d + next 7d; receipt drop box; geofence dwell beta; Gmail flagged) → Classifier (rules always; on-device FM iOS 26+; PCC for receipts/summaries iOS 27+, quota-checked, user can disable) → SuggestionStore (inbox) → Notifier (UNCalendarNotificationTrigger at event end +5 min; ≤20 pending, ≤2/day, quiet 21:00–08:00; actions Log it / Edit… / Not landlord work; re-check event on action) → confirm() → TimeEntry via single AppModelHost.
Calendar titles never leave the device. Low-confidence items shown as "Not sure this is landlord work", not hidden.
